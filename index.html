    ภาคิน เมฆสุวรรณ

    Phakin Meksuwan · BossZY

    เรียนวิทยาการคอมพิวเตอร์ ปี 2 ที่มหาวิทยาลัยขอนแก่น ชอบทำของที่เอาไปใช้ได้จริง ทั้งเว็บแบบ full-stack ระบบอัตโนมัติบนเดสก์ท็อปและเบราว์เซอร์ บอทเทรดบน MetaTrader 5 และงานที่ต่อ API ของโมเดลภาษา ช่วงหลังรับงานลูกค้าเพิ่ม ทั้งระบบหลังบ้าน เว็บ WordPress และงาน SEO

    เว็บนี้จัดงาน 0 ชิ้นเป็นราวเสื้อ หนึ่งราวคือหนึ่งหมวด หนึ่งตัวคือหนึ่งงาน ด้านหน้าพิมพ์ชื่องาน ด้านหลังพิมพ์ tech stack ส่วนป้ายที่ห้อยข้างเสื้อบอกว่าแต่ละเทคทำหน้าที่อะไร ราว NEW DROPS รวมงานใหม่ 0 ชิ้นไว้ให้ดูก่อน

    งานที่เป็นต้นแบบหรือใช้ข้อมูลจำลองจะเขียนกำกับไว้บนป้าย ส่วนงานลูกค้าจะไม่มีลิงก์จนกว่าลูกค้าจะอนุญาต
